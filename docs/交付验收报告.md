## 四、技术要点

1. **原生 GUI，无浏览器内核** — Python 3.13 + tkinter + Pillow，杜绝 WebView 类方案的启动开销。
2. **`--onedir` 而非 `--onefile`** — 关键性能决策。onefile 每次启动需解压 17 MB 到临时目录（5.6 s），onedir 直接加载（0.6-1.2 s），**快 7.5 倍**。
3. **Win32 剪贴板直写** — 手工构造 `BITMAPV5HEADER`（124 字节），直接写入 `CF_DIB`(8) + `CF_DIBV5`(17)，零依赖且保留 alpha 透明通道。
4. **分级快速解码管线**
   - JPEG 走 `Image.draft("RGB", size)` DCT 域缩略解码，仅解需要的数据。
   - 非动图先 `Image.reduce(factor)` 盒式滤波降采样，再解码。
   - 重采样算法按图大小切换：≤400 万像素用 `LANCZOS`（高质量），>400 万像素用 `BILINEAR`（LANCZOS 在超大图上性能崩溃）。
5. **Pillow 加载懒执行** — PIL 模块延迟到首次真正看图时才 import，压缩冷启动时间。
6. **动图懒解码** — GIF/WebP 动图内存只保留当前帧，避免多帧全解码吃内存。
7. **健壮性加固** — `Image.MAX_IMAGE_PIXELS = None` 关闭解压炸弹限制；`ImageFile.LOAD_TRUNCATED_IMAGES = True` 容错半损坏文件；`ImageOps.exif_transpose()` 校正 EXIF 方向。

## 八、待用户手动完成的事项

**设置默认图片程序**（用户已明确自行处理）：

Windows 11 内置 UCPD 内核驱动会拦截程序静默修改默认应用（微软反劫持机制，无法程序化绕过）。请按以下步骤手动设置：

1. 右键任意图片 → **打开方式** → **选择其他应用**
2. 选择 **FastImageViewer**（或"极速看图"）
3. 勾选 **始终使用此应用打开 .xxx 文件**
4. 对 `.jpg / .jpeg / .png / .gif / .bmp / .webp / .tiff / .tif / .ico` 逐个重复

或走：**设置 → 应用 → 默认应用 → 按文件类型选择默认应用**，搜索 `FastImageViewer` 后逐行指定。
